# 三视图构建工作流

## 输入要求

优先使用以下任一输入：

- 一张清晰、无遮挡、能辨认发型、脸型和主要服装的人物照片。
- 一张已经完成的角色正面、侧面、背面三视图。

照片只用于当次视觉参考，不进入最终 IP 包。输入信息不足以判断固定特征时，先说明缺口并询问，不擅自发明身份特征。

## 需要确认的角色信息

尽量从用户输入和图片中提取，只追问缺失项：

1. IP 显示名称。
2. 角色定位和希望传达的气质。
3. 必须保持的发型、脸型、体型或其他身份特征。
4. 标志性服装及稳定配色。
5. 固定配件及其佩戴位置。
6. 可以随场景改变的部分。
7. 明确禁止出现的特征、服装和风格漂移。

不要把敏感身份、联系方式或背景经历当作角色设定收集。

## 统一画面要求

生成一张包含正面、侧面、背面三个全身视图的角色三视图：

- 三个视图表现同一名角色，年龄、脸型、发型、肤色、体型和头身比例一致。
- 使用自然直立的中性姿势，手臂不要遮挡身体主要结构。
- 三个视图使用一致的画面尺度、地面线和身体高度。
- 侧面明确表现鼻、下巴、后脑、服装侧面和鞋型。
- 背面明确表现发型后部、服装背部、配件后部和鞋跟结构。
- 固定配件在所有可见角度保持同一侧、同一材质和同一形状。
- 服装纹样可以随角度自然变化，但色彩比例和设计语言保持一致。
- 使用纯白或极浅的无干扰背景，不加入道具、场景、标题或装饰边框。
- 默认使用彩色、半写实 2D 漫画语言：简洁色块、轻手绘轮廓、克制明暗、清晰结构。

三视图是唯一必需的角色视觉资产。不额外要求正面母版、表情表或动作表。

## 可直接使用的生成 brief

将方括号内容替换为用户确认的信息：

> 创建一张专业角色三视图，16:9 或适合容纳三个全身人物的横版画布，纯白背景。依次展示同一角色的正面、标准侧面和背面，全身完整、不裁切、相同高度、相同地面线、自然直立中性姿势。角色是[角色定位]，固定身份特征为[发型、脸型、肤色、体型、头身比例]，穿[标志性服装与稳定配色]，佩戴[固定配件及准确位置]。三个视图必须保持同一身份、身体比例、服装结构、配件侧别和鞋型。使用彩色、半写实 2D 漫画质感，简洁色块、轻手绘轮廓、克制明暗，成熟清晰。不要加入场景、道具、标题、阴影人物或额外角色。禁止[禁止特征]。输入人物照片只作为身份参考，不把照片或照片路径放进输出。

若工具支持参考图，把照片或已有三视图作为视觉参考传入，不仅依赖文字复述。

## 质量检查

逐项检查：

- 是否只有同一角色的三个角度，没有被理解为三名不同角色。
- 三个视图的头身比、肩宽、四肢长度和整体高度是否一致。
- 正面、侧面和背面是否齐全且方向明确。
- 发型轮廓、脸部结构和肤色是否稳定。
- 服装版型、主色、纹样语言和鞋型是否稳定。
- 固定配件是否处于正确身体一侧，形状和材质是否一致。
- 是否没有额外道具、文字、场景和无关人物。
- 是否没有因美化而改变年龄、体型或身份。

每次修正聚焦一个主要问题。修正后重新检查其他角度是否被连带改变。

## 用户确认

展示三视图并请用户确认以下两点：

1. 这是否是希望长期复用的同一角色身份。
2. 服装、配件、允许变化和禁止漂移是否准确。

收到确认后再生成角色规范和正式包。用户要求修改时保留原文件，使用新文件名或新的 `ip-id`，除非用户明确授权覆盖。
