# Jinchenma IP 文章插图

## 开始前

完整读取以下文件：

- `references/ip-pack-format.md`：初始化文章人物配置，导入、激活、切换并解析当前 IP。
- `references/illustration-style.md`：应用共享的 `jinchenma-surrealism` 视觉规范。
- `references/article-workflow.md`：确定图片数量、认知锚点、生成、保存和交付方式。

## 初始化并显示当前 IP

在分析文章前按照 `references/ip-pack-format.md` 完成人物解析：

1. 用户要求导入或切换人物时，先完成相应流程。
2. 第一次运行且没有文章人物配置时，在可交互场景先提示：`当前默认使用 Jinchenma。是否要更换为你自己的 IP 形象？` 用户选择更换时进入人物导入流程；选择不更换时使用内置金尘马。
3. 自定义人物只从文章 Skill 自己的 `ips/` 读取。Builder 包和外部文件只在明确导入时读取并复制。
4. 解析且只加载一个人物 IP 的 `manifest.json`、三视图和角色规范。
5. 开始生图前，用中间过程提示：`当前使用 IP：<displayName> (<ip-id>)`。

当前 IP 是人物身份，不是文章画风。所有人物 IP 默认继续使用 `jinchenma-surrealism`。

## 执行工作流

1. 读取完整文章或用户提供的全部文字。用户提供文章地址时获取完整正文，不根据标题单独推测内容。
2. 提炼核心观点、关键转折、文章情绪和真正值得视觉化的认知锚点。
3. 根据正文长度和信息密度决定图片数量，合并重复内容，不按章节平均覆盖。
4. 为每张图确定一个核心判断、一个超现实关系和 1—3 个主要物件。
5. 安排当前 IP 的叙事职责、人物尺度、动作和适合当前内容的情绪。
6. 列出少量必须准确呈现的短文字；文字语言跟随输入文章。
7. 在内部完成图片方案，不先输出方案，不等待二次确认。
8. 把当前人物 IP 的三视图作为同一角色的多角度参考，逐张独立生成，不用拼图代替。
9. 逐张检查文章含义、文字准确性、人物一致性和画面密度；每次只修正一个主要问题。
10. 按输出规则保存图片。最终回复保持简短，按顺序列出每张图片、用途、绝对路径和建议插入位置。

## 角色与风格边界

- 共享流程只从当前人物 IP 读取人物身份、服装、配件和稳定色。
- 切换人物只替换角色身份；不要改变文章分析、图片数量、认知锚点、隐喻设计、构图、保存和交付规则。
- 将三视图理解为同一角色的正面、侧面、背面，不生成三个角色。
- 让人物参与核心关系，但不要让人物压过文章观点。
- 不使用原始真人照片替代人物 IP 内的三视图。
- 不把一次生成中的偶然风格漂移写回人物 IP。

## 输出边界

- 文章插图优先保存到当前项目根目录的 `.jinchenma-assets/<article-slug>/`。
- 无项目、项目不可写或宿主沙箱禁止写入时，回退到 `~/.jinchenma-assets/<article-slug>/`。
- 不覆盖已有图片；使用 `-v2`、`-v3` 递增版本。
- `.jinchenma-assets/` 只保存文章插图，不保存三视图、角色规范或私人 IP。
- 默认把输入文章视为只读，只在最终回复中简要提供每张图片的插入位置。
- 只有用户明确要求把图片引用写入文章时，才修改原文章。
