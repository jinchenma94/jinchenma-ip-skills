# jinchenma-surrealism 文章插图规范

## 定位

为文章、帖子和观点制作简洁的杂志专栏概念插图。使用当前个人 IP 角色作为现实锚点，通过少量日常物件之间安静、不可能但逻辑准确的关系，把抽象观点转化为超现实漫画画面。

自定义 IP 只替换人物身份，不改变本文件中的概念提炼、构图和视觉语言。

## 内容优先级

按以下顺序组织画面：

1. 文章的核心观点。
2. 承载观点的单一超现实关系。
3. 帮助理解的必要文字和物件。
4. 当前 IP 角色的叙事职责、动作与表情。

让观点成为画面主角。让角色参与并触发核心关系，同时保持辅助性的视觉占比。

## 概念提炼

- 每张图只表达一个核心判断、结构或认知转折。
- 将抽象概念转化为一个可以看见的物理关系，例如影子停留、门框阻挡、重量失衡、镜像错位、物体悬浮或尺寸异常。
- 优先使用日常物件，依靠物件之间不可能成立的关系产生超现实感。
- 让画面第一眼清晰安静，第二眼显露异常，并能回到文章观点。
- 只保留使核心隐喻成立的元素。
- 不重复套用以往图片的具体物件和构图；为当前观点重新选择隐喻。

## 画面语言

- 使用 16:9 横版文章插图。
- 使用纯白背景并保留大面积留白。
- 使用完整的彩色、低饱和漫画表现，以简洁色块、轻手绘轮廓和克制明暗建立层次。
- 使用协调的有限色彩；当前 IP 包中的人物稳定色可以作为点缀，不强迫其他元素使用相同颜色。
- 允许物体的比例、空间、影子、方向和连接关系脱离现实逻辑。
- 保持画面成熟、安静、克制，带轻微冷幽默。
- 默认只使用一个超现实关系和 1—3 个主要物件。

## 当前 IP 角色

- 以当前包的 `assets.turnaround` 和 `characterSpec` 共同定义身份。
- 保持包内确定的身体比例、脸型、发型、服装、配件、鞋型和稳定配色。
- 不把角色改绘成简笔画、符号小人、写实真人或其他角色风格。
- 默认让单个人物约占画布面积的 10%—20%。
- 让角色承担观察、体验、触发、承受或改变超现实关系的必要职责。
- 根据文章情绪调整表情、头部角度、姿态和动作，不改变固定身份。
- 允许为了阶段、对照、并行、选择或内心冲突使用同一角色的 1—4 个分身；所有分身合计仍保持辅助性占比。

## 文字

- 图片内文字使用输入文章的主要语言。
- 使用必要短文字帮助识别关键概念、关系、状态或数字。
- 默认使用 1—3 处短文字；中文每处尽量控制在 2—8 个汉字，其他语言保持同等简洁。
- 让文字成为标签、批注、物件内容或视觉线索并自然参与构图。
- 使用文章中的准确概念，不用长句复述全文，不自行翻译专有名词。
- 生成前逐项列出必须逐字准确呈现的文字。

## 避免

- 商业宣传海报、课程课件、PPT 信息图和正式流程图。
- 完整写实场景、复杂电影光影、三维渲染感和摄影棚效果。
- 把文章概念拆成图标、卡片或功能模块逐项排列。
- 依靠怪物、复杂机械或装饰堆叠制造怪诞感。
- 多个互相竞争的隐喻、元素堆砌和过满构图。
- 大段解释文字、无关标题和重复标签。
- 让人物成为大幅商业海报主角或随场景发生身份漂移。

## 检查

- 是否一眼能识别核心关系，并在进一步观看时发现超现实异常。
- 是否只表达一个主要观点和一个超现实关系。
- 是否以纯白背景和大面积留白为主。
- 是否只有 1—3 个主要物件。
- 文字是否少、短、准确并对理解有帮助。
- 当前 IP 角色是否与所选包一致，动作和情绪是否适配内容。
- 角色是否参与核心关系但没有压过观点。
- 是否删除了不影响表达的物件、人物和说明。
