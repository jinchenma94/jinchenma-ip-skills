# 默认 3D 画风提示模板

把方括号替换为本次真实方案，只提交已解析的当前人物参考与必要画风参考。

> 生成一张 16:9 横版文章插图，纯白背景和大面积留白。输入图 1 是当前人物的同一角色多角度身份参考，保留其脸型、年龄、比例、发型、服装、配件侧别与稳定色，不复制参考姿势。输入图 2（如提供）仅为画风参考，不复制其中人物身份、场景或构图。读者看完应理解[正文准确意思]，采用[具体场景、对照、步骤、因果与结果或合适的隐喻]，可见场景/关系为[必要动作、变化及连接方向]；人物以[职责、动作、表情]参与，主要物件为[必要物件]。只表达这一主要意思，不强加超现实关系。人物与道具统一为柔和立体体块、哑光表面、克制明暗和必要的轻接触阴影，成年比例、成熟松弛。按当前人物身份色和已解析配色选必要颜色，皮肤自然、纸张和中性物件可用奶油白，背景保持白色。图内准确文字为[逐字列表或无文字]，关键文字在正文内嵌显示尺寸下无需放大也清楚可读，字号足够大、对比清楚；不要用缩小字体来容纳更多内容。人物保持辅助占比，不遮挡关系或挤压标签空间。人物和物件完整，关键手势、接触、方向与结果可读，上下左右有留白。不要厚黑描边、玩具比例、亮塑料、写实摄影、旅游背景、复杂房间、营销海报、额外人物、无关装饰或密集文字模块。

选择 2D 人物参考而明确要求 3D 道具时，在提示中写清人物保持 2D 表现的范围；默认组合不添加这种混合要求。截图模式不套用全图白底或重绘要求，按截图保护规则，只将选定人物表现融入原截图。
