# 金尘马 Jinchenma · 3D 人物规范

## 角色定位

成熟、松弛、友好、有行动力的成年男性创作者。采用用户确认的柔和立体插画表现；产物是带 3D 感的二维图片，不是三维模型。

## 视觉参考

- 本版本身份以 `../assets/turnaround.png` 为三视图参考，`../assets/character.png` 为单人物外观与材质补充。
- 三视图是同一个人的正面、侧面、背面，不是三个人。不要把单人物参考的姿势固定到所有场景。
- 同一包中的 2D 版本独立保存；本次选择 3D 时不混入 2D 描边与色块表现。

## 固定身份特征

- 成年男性、匀称体型，保持参考图的头身比例、脸型、自然肤色与四肢结构，不大头短腿、不肌肉化。
- 黑色自然蓬松短发、略不规则碎刘海；深色方框墨镜。
- 成熟而克制的表情与动作，可以随内容变化，不把友好微笑强加给严肃内容。

## 标志性服装与配件

- 深色底宽松短袖花衬衫，金黄和绿色为主要纹样色，少量橙色花纹；金黄与绿色及膝短裤。
- 服装纹样按可见表面自然变化，维持色彩比例与纹样尺度，不要求逐像素一致，不扩成海岛、旅游或热带场景。
- 人物本人的左腕：黑色圆角矩形智能手表，黑色屏幕和表带。
- 黑色宽面单带一字拖：露脚趾、开放后跟，无趾间立柱或 Y 形鞋带。
- 皮肤保持自然肤色。人物稳定色不要求道具或整张图片都重复使用。

## 允许变化

- 站、坐、蹲、观察、书写、搭建、讲解等与内容相关的动作，保持身体比例、身份与配件侧别。
- 墨镜默认正常佩戴；只在表达需要且用户允许时改变佩戴方式。
- 分身仅在内容需要时使用，每个分身应有独立职责并保持身份一致。

## 禁止漂移

- 不改西装、T 恤、外套、长裤、运动装或其他制服；不改脸型、年龄、肤色与发型轮廓。
- 不画成写实真人、玩具、娃娃、大头角色、简笔小人或厚黑边漫画。
- 不使用圆表盘、机械指针、金属链表带；不把手表换到右腕。
- 不把一字拖改成人字拖或封闭后跟鞋。

## 生图提示词片段

> 把输入三视图理解为同一位金尘马的三个角度。保留成年比例、脸型、自然肤色、黑色碎短发、深色方框墨镜、深底金黄绿纹样花衬衫与及膝短裤。左腕佩戴黑色圆角矩形智能手表，黑色宽面单带一字拖露脚趾且后跟开放。保持柔和立体体块、哑光表面和克制明暗，姿势与表情适配内容。衣服纹样只属于服装，不扩成背景；不要玩具比例、厚黑描边、塑料亮面或真人摄影感。

## 一致性检查清单

- [ ] 身份、成人比例、发型、脸型与自然肤色符合本版本参考。
- [ ] 花衬衫、及膝短裤、金黄绿识别色稳定。
- [ ] 黑色圆角矩形手表位于人物本人的左腕。
- [ ] 拖鞋为露脚趾、开放后跟的宽面单带一字拖。
- [ ] 动作与表情适合内容，身体与手指合理。
- [ ] 没有混入旧版厚描边、玩具比例或不必要背景。
