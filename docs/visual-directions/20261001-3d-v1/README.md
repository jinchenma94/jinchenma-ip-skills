## 视觉方向

成年人体比例，保留原有脸型、自然肤色、黑色短发和深色方框墨镜。宽松花衬衫、及膝短裤；人物本人的左腕佩戴黑色圆角矩形智能手表；黑色宽面一字拖露脚趾、开放后跟，无趾间立柱或 Y 形鞋带。

以柔和立体体块、克制光影和哑光表面表现成熟、松弛、有行动力的创作者。避免大头短腿、玩具比例、塑料亮面和厚重描边。服装纹样只属于衣服，不推导出旅游、海岛或热带场景。

## 候选配色

色值由本轮用户指定，独立保存在 [palette.json](palette.json)。当前仍是候选方案。

| 颜色 | 基色目标 | 应用 |
| --- | --- | --- |
| 黑 | `#1A1A1A` | 人物识别、配件、衣服底色和必要结构 |
| 金黄 | `#F7C948` | 人物识别和必要的突出物件 |
| 绿 | `#1F8F4B` | 人物纹样与辅助道具 |
| 青 | `#2EC4C7` | 必要的工作道具 |
| 橙 | `#FF8A3D` | 少量点缀 |
| 奶油白 | `#F8F6F1` | 纸张和中性物件 |

皮肤保持自然肤色，允许光照形成合理明暗。不要求每图用齐六色；正文样图继续白底，奶油白不自动成为背景。尚未建立颜色与文章概念的固定语义对应。基色目标不表示所有渲染像素精确等于这些色值。

## 核验与保留观察

四张图片均能完整解码，尺寸、模式和 SHA-256 与原生成记录一致。单人物图有 alpha 通道，透明像素已统计，四边均透明，主体最大 alpha 为 254（接近完全不透明）。部分图像查看器会显示隐藏的 RGB 背景色，应以浏览器 alpha 合成效果判断。

迁入后已在浏览器中核对：单人物白底合成未出现隐藏 RGB 中的金棕色光晕；192 px 高的人物仍可识别，服装细节开始并成色块；480 px 宽的场景仍能读出卡片插入文件夹的动作。

三视图与场景样图保留左腕手表和单带一字拖。服装纹样存在生成性变化，未逐像素锁定。

用户已确认这版立体感与整体视觉。服装纹样依然较密、小尺寸细节合并等观察继续保留，未擅自重画。
