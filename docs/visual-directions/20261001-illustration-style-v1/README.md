## 参考与范围

人物使用仓库内的 [3D 单人物候选](../../../skills/jinchenma-ip-article-illustrations/assets/ip-packs/jinchenma/variants/3d/assets/character.png)；材质、光影和道具配色参考已有 [整理卡片样图](../20261001-3d-v1/illustration-color-study.png)。颜色继续使用 [候选配色](../20261001-3d-v1/palette.json)。正式身份基准仍是内置人物包。

这轮只测试整体视觉：柔和立体体块、哑光表面、克制阴影、人物与道具协调、白底留白和小尺寸可读性。人物保持当前选用版本，未另做服装简化。这次确认后默认人物与画风已接入 Skill 的独立资源包；文章叙事流程未做完整重构。

## 文件与生成

- 三张 PNG：内置 `image_gen` 各自独立生成，输入仅为上述两张仓库内图片。
- `prompts/`：三次实际生成提示正文。输入绑定、调用选项、参考文件和输出文件哈希见 `generation.json`；记录仅使用仓库内相对路径。
- `preview.html`：浏览器预览，包含完整画面与 320 px 宽的小图比较，所有资源均位于本仓库，无联网资源加载。
- `generation.json`：实际结果、逐图检查、限制与采用状态。

原候选人物、场景和历史稿继续保留。未提交、未推送；默认采用本次确认的 3D 人物与画风，旧版独立保留。

## 评估方式

先看三张是否属于同一套视觉，再看各图姿势与物件是否清楚。检查人物比例、脸型、发型、左腕圆角矩形手表、一字拖、服装识别色及纹样密度。基色是材质目标，光照后的像素不会全部精确等于六个色值。

可视化检查与文件核验结果记录在 `generation.json`，不以提示词中的要求代替实际核验结论。生成性纹样和手部细节需要逐图观察。

本轮核验：三张 PNG 完整解码，输出、提示词和输入参考的哈希均已记录；预览资源全部加载。三张的左腕手表和单带一字拖均可见，体块、配色与白底基本一致。320 px 宽时主要动作仍可识别，铅笔尖和草图细节较弱，服装纹样并成色块。上下留白偏少，搭建样图的模型带有积木感，这些均保留供用户评估。
